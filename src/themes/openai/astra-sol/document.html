我们正式推出 GPT‑6.2 Astra 和 GPT‑6.2 Sol：前者是应对最棘手项目的全新前沿模型，后者则是面向日常工作的高效多面手。两款模型都能以更少的输出 Token，在高难度任务中取得更好的结果，让你在用量限制内完成更多工作。对企业和开发者而言，这意味着能以适合大规模应用的成本，获得前沿性能。

GPT‑6.2 Astra 为 AI 处理复杂专业工作的质量树立了新标杆。它生成的幻灯片、电子表格和文档更少带有 AI 写作痕迹，也更贴合你提供的模板和所在领域的惯例。它编写的代码更简洁，构建的前端在视觉和功能上都更出色，尤其适用于网站、游戏和 3D 设计。

在测试多步骤专业工作的 Agents’ Last Exam 中，GPT‑6.2 Astra 创下新高：得分比 GPT‑6 Astra 高 5.2 分，成本却不到其三分之一；比 Claude Fable 5.2 高 5.5 分，成本仅为其 5%。

我们认为，GPT-6.2 Astra 是全球最适合科学家使用的模型。它在 Terminal-Bench-Science 0.1 上创下新高，该基准测试评估模型在终端中开展科学工作的能力。GPT-6.2 Astra 的得分比 GPT-6 Astra 高 9 个百分点，成本却不到其三分之一。它还在 Vals Science Index 上创下新高，该评估要求模型解读真实生物数据，并通过实验推断模拟系统的运行方式。

在 API 中，GPT‑6.2 Astra 的输入和输出 Token 价格比 GPT‑6 Astra 低 20%，缓存输入价格则降低 60%（每百万 Token 的输入价格为 8 美元，缓存输入为 0.40 美元，输出为 40 美元）。GPT‑6.2 Sol 沿用 GPT‑6.1 Sol 的 API Token 定价。在多项基准测试中，两款模型的表现都接近或超越其他领先模型，而单项任务的成本仅为后者的一小部分。

GPT-6.2 Sol：我们日常工作的首选模型

相比 GPT‑6.1 Sol，GPT‑6.2 Sol 更智能、更高效，让你在同一付费套餐下完成更多任务。它能高效完成多步骤智能体工作流，文笔清晰自然，协作起来也得心应手。OpenAI 的许多员工都将它作为处理技术和非技术任务的默认模型。

在 Cognition 的 FrontierCode 2.0 中，GPT‑6.2 Sol 与 GPT‑6.2 Astra 的得分相差不到 0.5 分，成本约为其五分之一（两者均设为 Max）。

凭借速度和智能表现，它也非常适合处理工作之外人们寻求 AI 帮助的重要事务。在我们最近发布、用于衡量高难度日常任务表现的 LifeVal⁠ 评估中，GPT‑6.2 Sol 的得分高于 GPT‑6 Astra，成本约为其七分之一。

符合行业标准的专业成果

我们训练 GPT‑6.2 Astra，使其能够制作更清晰、设计更精良的幻灯片、电子表格和文档，更贴合法律、销售、金融和会计等领域专业人士的工作惯例。它的文字更直接、更具体，泛泛而谈的结论和冗余内容更少。

Harvey LAB‑AA v1.1 通过法律任务，测试模型能否从源文档中找到相关事实，按照详细的任务要求加以运用，并生成准确且满足所有要求的交付成果。GPT‑6.2 Astra 创下了新的最佳水平，通过率超过 Claude Fable 5.2 的两倍，成本约为其六分之一。我们面向律师定制的 GPT-6.2 Astra 配置——OpenAI 法律解决方案⁠——在这一基准测试中的得分更高。

我们的内部基准测试 GDPval v2 是 GDPval⁠ 的新一代版本，用于评估咨询、金融和设计等领域真实项目中复杂、长流程的工作流。GPT‑6.2 Astra 在我们测试的模型中表现领先，得分比 GPT‑6 Astra 高出 6.2 个百分点，同时输出 Token 用量减少了 22%。GPT‑6.2 Sol 的得分比 GPT‑6.1 Sol 提高了 5.3 分。

工作簿与备忘录

构建估值工作簿或撰写投资备忘录，首先需要从源文件中找到相关数据，并理清它们之间的关系。Artificial Analysis 的 AA‑AnalystAgent 使用真实电子表格和报告来测试这项工作。在其中一项任务中，模型需要根据加利福尼亚州 Medicaid 的支出报告，计算该计划在医疗转运方面的支出。GPT‑6.2 Astra 创下新高：有 62.5% 的问题在全部五次独立尝试中均得到正确回答。

幻灯片

在幻灯片设计和遵循幻灯片模板方面，GPT‑6.2 Astra 是我们迄今最出色的模型，无论提供的是原始文件，还是仅仅一张截图。它能够匹配布局、配色和排版，精确到字号，并将模板的写作风格延续到新幻灯片中。早期测试者发现，这些演示文稿只需较少修改就更容易直接使用，因为标题开门见山地指出核心结论，正文简明扼要，聚焦读者需要的细节。

计算机使用与交互式网页设计

GPT‑6.2 Astra 的计算机操作更加精准，能在 CAD 和仿真工具中细化到单个零件及其连接关系。工程师可以利用这些更精细的细节，检查组件的配合情况，观察设计在运动时载荷如何转移，并在制作原型前测试修改方案。

驾驶仿真

我们要求 GPT‑6.2 Astra 将汽车在山路上行驶时的底盘动力学过程可视化。Astra 创建了 3D 模型，编写 Python 求解器来模拟轮胎与悬架之间复杂的动力学关系，再用 Blender 将结果制作成动画。这让工程师能够快速测试新设计，并持续提高仿真精度。

机械设计与装配

GPT‑6.2 Astra 可以逐个零件地为机械系统建模，让工程师能够展示其装配过程，并测试设计变化如何影响系统的运行表现。

从 CAD 设计到纸灯

我们的团队使用 GPT‑6.2 Astra，将芝加哥滨海城双塔的扇贝形阳台转化为一盏灯的设计。视频展示了从参考照片、CAD 设计修改，到手工组装成实体灯具的全过程。你可以使用 GPT-6.2 Astra 生成的网站，制作属于自己的纸灯。

GPT‑6.2 Astra 将更强的视觉推理能力带入网页设计，选用赋予每个网站独特外观的布局和图像，并围绕网站的实际目标构建各个元素。

视觉推理和计算机使用能力的这些提升，也延伸到了 3D 设计领域。GPT‑6.2 Astra 和 Sol 可以将书面需求转化为浏览器中的交互体验，既能制作可玩的弹球台，也能重建可从不同角度探索的罗马斗兽场。在 Artificial Analysis 的 AA‑3D 评估中，人类评审会在不知道模型身份的情况下，体验根据同一提示词构建的两个作品，并投票选出更喜欢的一个。GPT‑6.2 Astra 以 1,318 的 Elo 评分位居第一，其后是 1,271 分的 Claude Fable 5.2 和 1,259 分的 GPT‑6.2 Sol。

更高效的工作流，更简洁的代码风格

GPT‑6.2 Astra 在任务执行方式上有了更好的判断力，能够根据工作流选择合适的工具和投入程度，并判断何时应使用插件、何时应直接操作计算机。

在编程方面，GPT-6.2 Astra 更擅长在现有代码库中实现和测试复杂改动。早期测试者反馈，它的代码风格更简洁，测试更有针对性，需要的修改轮次也更少。

网络安全能力

GPT‑6.2 Astra 和 GPT-6.2 Sol 的网络安全能力再次实现显著跃升。它们能更有效地发现和利用漏洞，编写更安全的代码，生成更好的补丁，并在多项评估中大幅提升 Token 使用效率。与 GPT‑6 Astra⁠ 一样，6.2 Astra 和 Sol 均达到我们准备框架⁠中网络安全能力的“严重”级别阈值。

鉴于 GPT‑6.2 Astra 和 Sol 的能力有所提升，我们在推出这两个模型时，针对风险较高的网络安全辅助任务采取了更严格的安全防护措施。这些防护措施降低了滥用风险，但也限制了部分合法的漏洞研究和安全测试工作流。目前，通过 OpenAI Daybreak⁠，网络防御人员除了可以使用 GPT-6 Astra 的 Alpha 版本，还可以在 Daybreak Blue 上使用对网络安全请求拒绝更少的 GPT‑6 Sol，并在 Daybreak Red 上使用 GPT‑6 Cyber⁠ 进行高级、经授权的安全测试。我们将努力把 GPT‑6.2 模型引入 Daybreak。

下面重点展示关键基准测试结果，测试采用内部配置，并关闭了网络安全防护措施和分类器。完整结果和方法详见配套系统卡⁠（在新窗口中打开）。

助力网络防御人员赢得优势

开发者越来越依赖编程智能体编写生产软件，与此同时，能力更强的智能体也降低了发现和利用漏洞的门槛。PHP2Shell⁠（在新窗口中打开） 展示了 AI 如何帮助研究人员发现严重漏洞。在 GPT‑6.2 Astra 和 Sol 中，我们将防御能力作为核心重点，引入新的训练信号，帮助开发者预防和修复这些漏洞——从一开始就编写安全代码，并生成保留预期行为的补丁。

安全与对齐

我们采用迄今最强的安全防护措施来部署 GPT-6.2 Astra 和 Sol。我们收紧了限制，并强化了用于监测模型⁠和在必要时进行干预⁠的系统。

与 GPT-6 Astra 一样，GPT-6.2 Astra 和 Sol 除了达到网络安全能力的“严重”级别阈值，也都达到我们准备框架⁠中生物和化学能力的“高”级别阈值。我们已实施防护措施来缓解相关风险，并加强了对一系列潜在两用性生物和网络安全请求的限制。

关于安全防护措施和测试的更多详情，请参阅 GPT-6.2 系统卡⁠（在新窗口中打开）。

AI 研究能力与安全防护措施

GPT-6.2 Astra 是我们首个对外发布、达到“AI 自我改进”高阈值的模型，该指标衡量模型加速 AI 研究的能力。“高”级别代表我们的评估认为：相较于 2024 年的基线，该模型带来的影响相当于为每位 OpenAI 研究人员额外配备一名能力出色的研究工程师作为助手。我们跟踪这项能力，是因为能够帮助开发未来 AI 系统的模型也可能引入新的安全风险，例如推动进展的速度快于安全防护措施或人类监督的适应速度。

为应对这些风险，我们在模型训练和部署流程中加入了更多监督与控制措施。在扩大 GPT-6.2 Astra 的内部访问范围之前，我们评估了其对齐情况，并确认各个阶段所需的安全防护措施均已到位。我们加强了研究环境中的隔离防护⁠，并使用能力最强的模型测试这些措施。我们还构建了 Control Room⁠，该系统可跟踪研究工作负载，并在需要干预时阻止模型继续输出。我们扩展后的监测机制⁠会检查模型在内部工作负载和受支持的外部部署中的推理与行动。它可以自动标记未经授权的行为，并在支持的情况下暂停工作负载或对话。

对齐

两款模型在大多数对齐评估中的表现与 GPT-6 Astra 相近，并在模拟职场任务中采取了更少的不当行动。不过，在两项测试中，它们更容易漏报阻碍工作的问题，例如文件缺失或搜索工具不可用。我们在 Codex 中添加了指令，大幅减少了此类遗漏，并将继续研究这一行为。

定价与可用性

即日起，所有 Plus、Pro、Enterprise 和 Edu 用户都可在 ChatGPT 工作和 Codex 中使用 GPT-6.2 Astra 和 Sol。Pro 500 订阅用户可为这两款模型启用超高速模式。我们还首次向 Pro 200 订阅用户开放超高速模式，率先支持 GPT-6.2 Sol。符合条件的 Enterprise 和 Edu 用户，在工作空间管理员启用后，也可获得相同访问权限。开发者也可通过 OpenAI API 使用 gpt-6.2-astra 和 gpt-6.2-sol，两款模型在发布时均支持超高速模式。

得益于更高的 Token 使用效率、输入和输出 Token 价格降低 20%，以及缓存输入 Token 价格进一步降低 60%，GPT‑6.2 Astra 的单项任务成本显著低于 GPT‑6 Astra。标准 API 定价按每百万 Token 计：输入 8 美元，缓存输入 0.40 美元，输出 40 美元。GPT‑6.2 Sol 沿用 GPT‑6.1 Sol 的定价，每百万 Token 的输入价格为 2 美元，缓存输入为 0.10 美元，输出为 10 美元。

使用 GPT-6.2 Astra 和 Sol 时，为提高缓存复用率、帮助降低成本和延迟，并跨轮次保留推理，我们建议保持提示词前缀不变，并在对话中追加新指令⁠（在新窗口中打开）。

我们向两款模型提供了同一套虚构农业科技公司 Alderfen Field Systems 的财务报表、经营假设和市场数据，要求它们构建一个可编辑的 Excel 工作簿，按业务板块预测截至 2031 年的收入，并检查三张财务报表能否勾稽一致。工作簿还需要按 8% 的折现率和 3% 的永续增长率估算摊薄后每股价值，展示支撑参考股价所需的增长率，并说明估值如何随这些假设的变化而变化。

GPT‑6.2 Astra 将收入构成以及从企业价值到每股价值的计算衔接放在敏感性分析表旁边。读者可以看到哪些业务推动了预测结果，并追溯折现现金流、现金与投资以及摊薄后股数如何影响每股估值。GPT‑6 Astra 则将收入明细放在单独的工作表中，将估值衔接计算放在工作表较下方的位置。
