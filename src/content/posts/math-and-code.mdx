## 数学的表达

行内公式 $e^{i\pi}+1=0$ 可以自然地融入文字。独立公式则为推导留出空间：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx=\sqrt{\pi}
$$

$$
A=\begin{pmatrix}1&2\\3&4\end{pmatrix},\quad \nabla f=\left(\frac{\partial f}{\partial x},\frac{\partial f}{\partial y}\right)
$$

## 用代码验证

```typescript
function fibonacci(n: number): number {
  if (n < 2) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}
console.log(fibonacci(10));
```
