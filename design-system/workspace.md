# 创作者工作台

用途：个人博客，连接文章、数学实验和项目。

配色：背景 #f4f6fa、纸面 #ffffff、正文 #202a3b、次要文字 #627086、强调 #325ad5、边线 #e1e6ef。暗色模式保持同样层级。
字体：标题与正文使用 MiSans 简体，代码使用 Anthropic Mono。字号 14/16/20/28/40，正文行高 1.9。

布局：桌面左侧窄导航；主区左对齐，首屏显示介绍和一篇真实实验；旁栏放项目入口与标签。移动端恢复顶部导航，旁栏移到内容后。

[个人导航] [介绍与交互实验 / 最新文章] [项目与话题]

审查：舍弃检索得到的营销转化布局，不使用社会证明、重复 CTA、全大写标签。波形实验作为唯一主要视觉亮点。其余区块使用清晰的文章标题、日期与摘要。保留 study/editorial/terminal 原主题。
