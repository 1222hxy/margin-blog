## 有意适配

| 原站行为 | 本地行为 | 原因与重考虑条件 |
| --- | --- | --- |
| 四个 CDN origin | 等字节长度的根相对前缀 | 保持 Flight 定长文本记录，所有文件本地服务；如运行自有 CDN 可恢复来源映射 |
| 统计脚本与遥测请求 | 去掉统计 script 标签，适配器返回中性响应 | 不向原站发送复刻站访问数据；若接入自有统计另行登记 |
| 源 TTS API 返回绝对 MP3 URL | 快照元数据在响应时补当前 origin，18 段原 MP3 本地播放 | 原播放器把非 HTTP 字符串当主机名；源控件和音频不改 |
| `/backend/gate/*` | 4 个 `{ok:true}` 本地桩 | 原站服务端不提供可移植实现，不等同实现原服务 |
| 站内预取和跨文章链接 | 未捕获 `_rsc` 返回 HTML 类型以触发原版文档导航；普通其他文章链接跳官网 | 本次只复刻单篇；补录更多页面后可扩展范围 |
| 实时搜索结果和其他线上 API | 不虚构后台结果 | 未获取官网后端实现；搜索窗口、输入和关闭保留原版，实时结果不在覆盖范围 |
| 原站索引与原始标识 | 原始标识保留，HTTP noindex，NOTICE 链接 | 用户要求整页原样；当前不插入改变像素的横幅 |

导入器与独立字节校验器分别实现转换，校验两条路由最终 HTML 与已登记文档逐字节相等。没有自定义视觉 CSS、替代字体或重新实现播放器、菜单、目录、搜索弹窗。

`.gitattributes` 对原始响应副本禁用换行转换和空白检查；原版压缩脚本及着色器的尾随空白原样保留，不用格式化破坏哈希。

## 对拍与验收

参考端在原始 openai.com URL 回放不可变响应体；测试端使用 Astro 生产构建。两端不共享改写器。字体就绪，拒绝非必要 Cookie，走完整页加载懒图片；仅测试中隐藏文本光标。Chromium、DPR 1，桌面 1440×1000、手机 390×844。

四轮按轮次、视口、参考端/本地端交错运行，覆盖 12 个状态。独立 Python/Pillow 脚本按解码后的 RGB 像素比较，同时计算每侧对首轮的自差。结果见 `compare/openai-exact/pixels.json`：所有受测跨端、自差均 0 像素，本地 CLEAN 为 0。首轮 24 张截图随仓库保存，报告另记四轮全部 PNG 的 SHA-256。原始音频实际播放和暂停、搜索输入/关闭、手机导航与固定目录另有浏览器测试。

**覆盖限制**：全站 CSS 引用另有 69 个未使用资源源站返回 403，详见 `openai-exact-unavailable.json`。参考端还会尝试未捕获的其他页面预取与统计请求，均在 `capture.json` 明确保留，不能宣称参考镜像全站 CLEAN=0 或 GAP=0。所有受测可见图片和字体均加载完成，未将双方同缺图误判为一致。当前不宣称完整 L2/L3 重构通过，也不把本次快照结论推广至所有视口或未来官网版本。
